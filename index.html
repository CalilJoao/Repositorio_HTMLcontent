Galeria HTML Content Secure

Montado por João Rossini

12 medidas DAX prontas para o visual certificado (o antigo HTML Content lite), cada uma com prévia ao vivo. Todas seguem as regras dessa edição: sem script e sem nada carregado de fora, só <style>, CSS inline e SVG.

As prévias usam dados de exemplo. No Power BI, o visual mostra o que a medida devolver.

Playground

Cole o HTML gerado pela sua medida (ou abra um template com "Testar"). A prévia remove o que o Secure removeria, e a lista aponta o que deve quebrar. Depois converta o HTML numa medida DAX pronta para colar.

    Regras que evitam dor de cabeça
    
  
    
    
    Número no CSS sempre com ponto
    Num modelo pt-BR, FORMAT(0.455,"0.0") devolve "45,5" e quebra o width. Use FORMAT(x,"0.0","en-US") em tudo que for parar no CSS ou no SVG.
    
    
    Aspas simples dentro do HTML
    A string DAX usa aspas duplas. Escreva os atributos com aspas simples (style='...') e não vai precisar escapar nada.
    
    
    Nada externo
    Fontes da web, @import, @font-face e imagens por URL são bloqueados. Use fontes do sistema (Segoe UI) e imagens como data:image/png;base64,....
    
    
    Animação permitida
    @keyframes funciona. Em SVG, <animate> funciona em opacity, transform, fill e stroke (a partir da versão 1.6.1).
    
    
    Escape textos do modelo
    Se um nome de categoria pode ter < ou &, envolva-o em SUBSTITUTE(SUBSTITUTE(txt,"&","&amp;"),"<","&lt;").
    
    
    Listas com CONCATENATEX
    Ranking, tabela e sparkline montam uma linha por item com CONCATENATEX sobre um TOPN ou ADDCOLUMNS. A ordem vai nos dois últimos argumentos.
