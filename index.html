Galeria HTML Content Secure

Montado por João Rossini

12 medidas DAX prontas para o visual certificado (o antigo HTML Content lite). Abra um template para personalizar título, unidade, abreviação, se maior ou menor é melhor e as faixas de cor, ou para editar o HTML à mão. Todas seguem as regras dessa edição: sem script e sem nada carregado de fora, só <style>, CSS inline e SVG.

As prévias usam dados de exemplo. No Power BI, o visual mostra o que a medida devolver.

Tem um HTML seu ou feito com IA?

Abra o editor livre, cole o HTML e veja a prévia, o que o Secure vai bloquear e a medida DAX pronta. Escreva {{pct}} onde quiser o percentual do simulador.

Regras que evitam dor de cabeça

Número no CSS sempre com ponto

Num modelo pt-BR, FORMAT(0.455,"0.0") devolve "45,5" e quebra o width. Use FORMAT(x,"0.0","en-US") em tudo que for parar no CSS ou no SVG.

Aspas simples dentro do HTML

A string DAX usa aspas duplas. Escreva os atributos com aspas simples (style='...') e não vai precisar escapar nada.

Nada externo

Fontes da web, @import, @font-face e imagens por URL são bloqueados. Use fontes do sistema (Segoe UI) e imagens como data:image/png;base64,....

Animação permitida

@keyframes funciona. Em SVG, <animate> funciona em opacity, transform, fill e stroke (a partir da versão 1.6.1).

Escape textos do modelo

Se um nome de categoria pode ter < ou &, envolva-o em SUBSTITUTE(SUBSTITUTE(txt,"&","&amp;"),"<","&lt;").

Listas com CONCATENATEX

Ranking, tabela e sparkline montam uma linha por item com CONCATENATEX sobre um TOPN ou ADDCOLUMNS. A ordem vai nos dois últimos argumentos.

Onde achar mais

  • HTML Content Secure (ex-lite) na AppSource, o visual certificado de Daniel Marsh-Patrick usado por todos os templates.
  • html-content.com: Sanitization, a lista do que a edição Secure filtra (CSS, URLs, atributos, animações).
  • html-content.com: Accepted Tags, as tags HTML e SVG aceitas.
  • html-content.com: Compare editions, as diferenças entre a regular e a Secure.
  • SteCiu01/Power-BI-HTML-Templates: .pbix com cards de KPI e cascata. Ele foi feito para a edição regular, então teste antes de usar no Secure.
  • phData: cards HTML dinâmicos, com uma tabela de configuração para gerar vários cards a partir de uma só medida.
